Before You Start

Set up your practice database once, learn the five tables, then work through the questions.

1Set up the database

  1. In SQL Server Management Studio, create a new database (for example AmerimedPractice) and select it.
  2. Open data_setup.sql from the healthcare folder and run it once. It creates the healthcare schema with 100 patients, 50 doctors, 50 medications, 240 encounters and 164 prescriptions.
  3. For DDL, Constraints and DML questions, wrap your work in BEGIN TRAN … ROLLBACK TRAN so the data stays the same for the next question.

2The tables

PatientsPatientID (PK), PatientName, PatientNumber, Region
DoctorsDoctorID (PK), DoctorName, LicenseNumber, Specialty
MedicationsMedicationID (PK), MedicationName, MedicationCode, UnitCost
EncountersEncounterID (PK), PatientID, DoctorID, EncounterType (A office · B follow-up · C telehealth), Status (Open · Closed · Pending), Charge, EncounterDate, StartedAt, RecordedAt, Note, BackupNote, ParentEncounterID
PrescriptionsPrescriptionID (PK), EncounterID, MedicationID, PrescriptionReference, Quantity

3How to practise

  • Start with Beginner, then Intermediate, then Advanced. Use the level slider to focus.
  • Write and run your own SQL first. Then press Check expected result to compare the row count and values.
  • A different query can still be correct. If there is no ORDER BY, your rows may come back in another order.
  • Tick Done to track your progress. It is saved in this browser only.

4How to submit

  • Save one .sql file per topic, named TOPIC_YourName.sql, e.g. JOINS_PriyaSharma.sql.
  • Put the question ID above each answer as a comment, e.g. -- JOINS-B03.
  • Under each query, note how many rows it returned.
  • For "explain" questions, write your answer as a comment.
